# 더샵 탕정인피니티시티 2차 입주자 현장안내 (초안)

입주예정자 전용 현장안내 웹앱입니다. 입주자 인증(회원가입 → 관리자 승인) 후에만
아파트 소개, 현장사진, 공정진행현황, 품질관리, 안전관리, 현장특화사항, 공지사항을
열람할 수 있습니다. 원가관리는 관리자만 접근 가능합니다.

## 기술 스택

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma + SQLite (로컬 파일 DB, `prisma/dev.db`)
- Auth.js(NextAuth) v5 — 휴대전화번호 + 비밀번호 로그인
- recharts — 공정율 선그래프
- xlsx — 공정표 엑셀 파싱
- adm-zip — 업로드된 PPTX(zip) 내부 이미지 추출

## 처음 실행하는 방법

```bash
npm install
npm run db:push    # SQLite DB 스키마 생성
npm run db:seed     # 관리자 계정 생성
npm run dev
```

브라우저에서 http://localhost:3000 접속.

### 기본 관리자 계정 (반드시 로그인 후 비밀번호를 변경하세요)

- 휴대전화번호: `01000000000`
- 비밀번호: `admin1234`

> 현재 운영 중인 실제 계정 정보는 코드에 남기지 않았습니다. 관리자 계정 정보를
> 바꾸려면 `prisma/seed.js`를 수정하거나 Prisma Studio(`npm run db:studio`)에서
> `User` 테이블을 직접 수정하세요.

## 화면/기능 구성

| 메뉴 | 접근 권한 | 설명 |
| --- | --- | --- |
| 아파트 소개 | 입주자 | 단지 개요, 투시도, 평형 구성, 발주/설계/감리/시공 정보 |
| 현장사진 | 입주자 | 2024년 4월부터 매달 사진 등록/열람, 클릭 시 팝업 확대 (등록은 관리자만) |
| 공정진행현황 | 입주자 | 사업일정·마일스톤 타임라인 + 공정표 엑셀 업로드 시 계획 대비 실적 선그래프 |
| 품질관리 | 입주자 | 품질 개선 사례(사진 4열 그리드 + 캡션), 등록은 관리자만 |
| 안전관리 | 입주자 | 안전 관리 활동(사진 4열 그리드 + 캡션), 등록은 관리자만 |
| 현장특화사항 | 입주자 | 조경특화 / 조형물특화 / 주민공동시설 특화 / 입면특화 / 기타, PDF·PPT 첨부 시 리스트업 |
| 공지사항 | 입주자 | 관리자만 작성/삭제, 입주자는 열람만 |
| 원가관리 | **관리자만** | 실행현황 / 매출현황 / 채권현황 — 네비게이션에도 관리자에게만 노출, URL 직접 접근도 미들웨어에서 차단 |
| 관리자 > 입주자 인증 관리 | 관리자만 | 가입 신청 목록 확인 및 승인/반려 |

## 회원가입(입주자 인증) 흐름

1. `/signup`에서 이름/동/호수/휴대전화번호/비밀번호 입력 → 상태 `PENDING`으로 저장
2. 관리자가 `/admin/residents`에서 동/호수 정보를 확인 후 **승인**
3. 승인된 입주자만 로그인 후 전체 메뉴 열람 가능

> 초안 단계에서는 관리자가 수기로 승인하는 방식으로 "입주자 인증"을 구현했습니다.
> 추후 계약자 명부(엑셀 등)와 동/호수·이름을 대조하는 자동 인증 로직으로 고도화할 수 있습니다.

## 공정진행현황 입력

공정표 엑셀 업로드 대신, 관리자가 월/차수 라벨(예: `2026-09`)과 계획·실적 공정율(%)을
직접 입력하는 방식입니다 (`app/(app)/progress/progress-input-form.tsx`,
`app/api/progress/route.ts`). 이미 입력된 라벨을 다시 저장하면 해당 값이 수정되고,
새 라벨이면 맨 뒤에 추가됩니다. "현재 실적/계획 공정율"과 "차이" 카드, 선그래프는 저장된
값을 바탕으로 자동으로 갱신됩니다. 실적을 비워두면 그래프에서 해당 시점은 계획선(점선)만
표시됩니다.

## 품질관리 / 안전관리 / 현장특화사항 PPTX 업로드

관리자가 PPTX 파일을 업로드하면 슬라이드 안의 사진을 자동으로 추출해 4열 그리드로
보여줍니다 (`lib/extract-pptx-images.ts`, adm-zip으로 `ppt/media/*` 이미지를
그대로 꺼내는 방식이라 LibreOffice 등 외부 프로그램이 필요 없습니다).

## 원가관리(실행현황/매출현황/채권현황) 수동 입력

원가관리 페이지는 관리자가 각 구간(실행현황/매출현황/채권현황)의 "편집" 버튼을
누르면 표(행/열 추가·삭제 가능), 비고, 이미지를 직접 입력하는 방식입니다
(`components/cost-section-form.tsx`, `app/api/cost-section/route.ts`). 서버리스
환경에서도 그대로 동작하도록 PPTX 자동 파싱(Python 의존) 대신 수동 입력으로
설계되어 있습니다.

## 업로드 파일 저장 위치

- 현장사진: `public/uploads/photos/{YYYY-MM}/`
- 개선사항/품질/안전/원가관리 자료: `public/uploads/improvements/`
- PPTX에서 추출한 이미지: `public/uploads/improvements/images/`

로컬 파일시스템에 저장되는 방식이라, 실제 운영 배포 시에는 S3 등 외부 스토리지로
교체하는 것을 권장합니다. (`lib/upload.ts` 참고)
